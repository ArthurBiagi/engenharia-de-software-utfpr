# 🎓 Engenharia de Software - UTFPR

Este repositório foi criado com o objetivo de centralizar, organizar e documentar todos os códigos, projetos, laboratórios e atividades práticas desenvolvidos ao longo da minha graduação em **Engenharia de Software** na **Universidade Tecnológica Federal do Paraná (UTFPR)**, campus Cornélio Procópio.

O foco principal é registrar a minha evolução técnica, manter um histórico acadêmico acessível e aplicar na prática os conceitos de versionamento de código e boas práticas de desenvolvimento.

---

## 📂 Organização das Disciplinas

As atividades estão divididas por pastas nomeadas de acordo com as disciplinas estudadas na grade curricular:

### 🔹 Fundamentos & Lógica de Programação
**[`algoritmos-logica/`](./algoritmos-logica)**
  * Resolução de problemas matemáticos, lógica pura, estruturas condicionais e de repetição.
  * Implementação de estruturas de armazenamento e organização de dados (Vetores, Matrizes, Listas, Filas, Pilhas e Ponteiros).
  * *Linguagem principal utilizada:* C / C#.

### 🔹 Engenharia & Processos de Software
**[`engenharia-de-requisitos/`](./engenharia-de-requisitos)**
  * Artefatos, elicitação, análise e especificação de requisitos de software (Histórias de Usuário, Casos de Uso, Diagramas).

### 🔹 Banco de Dados
**[`banco-de-dados/`](./banco-de-dados)**
  * Modelagem conceitual, lógica e física de dados (Modelos Entidade-Relacionamento).
  * **Scripts e Exercícios Práticos:** Resolução de listas de exercícios de fixação e desafios em SQL focados em consultas complexas, manipulação de dados (DML) e   definição de estruturas (DDL).
  * *Tecnologia principal utilizada:* SQL (MySQL / PostgreSQL / SQL Server).

### ◆ Programação Orientada a Objetos
**[`poo/`](./poo)**
* Resolução de exercícios e projetos focados nos pilares da POO (Abstração, Encapsulamento, Herança e Polimorfismo).
* Implementação de conceitos essenciais como classes, objetos, atributos, métodos, construtores e tratamento de exceções.
* *Linguagem principal utilizada:* Java.

 ---
## 🛠️ Tecnologias Utilizadas nesses Projetos
* **Linguagens:** C / C# / Java
* **Banco de Dados:** SQL 
* **Ferramentas:** Git, GitHub, VS Code, Visual Studio
