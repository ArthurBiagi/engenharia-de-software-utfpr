# ☕ Programação Orientada a Objetos (POO I)

Este diretório reúne os exercícios, desafios e projetos práticos desenvolvidos ao longo da disciplina. O código está organizado em subpastas nomeadas de acordo com os mecanismos da linguagem, bibliotecas e conceitos aplicados.

---

## 📂 Estrutura do Diretório

### 📁 `01-fundamentos-java/`
* **Mecanismos:** Sintaxe base, tipos de dados, estruturas condicionais/repetição e entrada/saída de dados via console.
* **Conceitos:** Transição da lógica procedural para a estrutura de classes e métodos estáticos.

### 📁 `02-pilares-poo/`
* **Mecanismos:** Criação de classes, objetos, atributos, métodos, construtores e modificadores de acesso (`public`, `private`, `protected`).
* **Conceitos:** Aplicação prática dos 4 pilares: Abstração, Encapsulamento, Herança e Polimorfismo (`@Override`).

### 📁 `03-interfaces-e-classes-abstratas/`
* **Mecanismos:** Contratos de código, abstração total/parcial e reutilização de código.
* **Conceitos:** Modelagem de sistemas com acoplamento fraco e implementação de múltiplas interfaces.

### 📁 `04-tratamento-de-excecoes/`
* **Mecanismos:** Blocos `try-catch-finally`, propagação com `throws` e criação de classes de exceções personalizadas (`Exception` / `RuntimeException`).
* **Conceitos:** Controle de erros em tempo de execução e construção de programas robustos.

### 📁 `05-colecoes-e-generics/`
* **Mecanismos:** Java Collections Framework (`List`, `ArrayList`, `Set`, `HashSet`, `Map`, `HashMap`) e tipos genéricos (`<T>`).
* **Conceitos:** Manipulação e organização dinâmica de estruturas de dados na memória.

### 📁 `06-manipulacao-de-arquivos/`
* **Mecanismos:** Classes I/O nativas (`File`, `Scanner`, `BufferedReader`, `BufferedWriter`, `FileWriter`).
* **Conceitos:** Leitura e escrita de dados para persistência em arquivos de texto local (`.txt` / `.csv`).

* **Linguagem:** Java (JDK 21)
* **Paradigmas:** Orientação a Objetos (POO)
