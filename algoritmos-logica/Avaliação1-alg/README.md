# 📝 Avaliação 1 - Algoritmos II (UTFPR)

Códigos desenvolvidos para a primeira avaliação prática da disciplina, focados em gerenciamento avançado de memória na linguagem C.

## 📋 Resumo das Questões

* **`exercicio1.c` (Vetor Dinâmico):** Criação de vetor modularizado com lógica de **realocação dinâmica de memória (`realloc`)** que expande o tamanho do bloco a cada 10 novos elementos inseridos.
* **`exercicio2.c` (Ponteiros e Filtros):** Implementação da função `int *Maiores(...)` para filtrar dados e realizar a **alocação dinâmica sob demanda** com o tamanho exato dos elementos filtrados.
* **`exercicio3.c` (Validação):** Programa completo para testar e validar o comportamento e o retorno da função criada no exercício anterior.
* **`exercicio4.c` (Matrizes Bidimensionais):** Aplicação que valida a ordem matemática de duas matrizes `MxN`, realiza a **alocação dinâmica bidimensional** e processa a soma com dados randômicos.

## 🛠️ Tecnologias
* Linguagem C
* Alocação Dinâmica (`malloc`, `realloc`, `free`)
* Ponteiros e Matrizes
